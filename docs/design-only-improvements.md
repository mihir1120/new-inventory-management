# Ashokvatika Design Improvement Report

Date: 2026-05-14

This document focuses only on visual design and user experience improvements for the Ashokvatika app.

## 1. Overall Direction

The app already has a recognizable identity because of its orange and green palette, logo presence, and category-based navigation. The next design step is not a full redesign. It is a refinement pass that makes the app feel more premium, more consistent, and easier to use during real work.

The strongest design goal should be:

- trust
- clarity
- consistency
- faster scanning

## 2. Main Design Improvements

### A. Improve the login screen

The login screen is clean, but it can feel more professional and more intentional.

Suggested improvements:

- Use empty input fields by default so the screen feels cleaner and safer.
- Add a short subtitle below the logo such as "Admin inventory and OTC panel".
- Add a proper primary sign-in button instead of depending mainly on the trailing confirmation icon.
- Reduce visual emphasis on secondary controls like the visibility toggle.
- Use stronger visual feedback for loading, success, and error states.

Desired result:

- The first screen should immediately feel like a polished business product.

### B. Create one consistent header style

Many screens use similar top navigation, but the spacing and alignment are not always uniform.

Suggested improvements:

- Use one fixed header system for back button, title, search, and optional actions.
- Keep the same top spacing, icon size, and alignment on OTC, Open Cart, Closed Deals, inventory, docs, and art screens.
- Use consistent title placement and safe-area padding across phone sizes.
- Avoid one-off header adjustments screen by screen.

Desired result:

- All screens should feel like they belong to one deliberate system.

### C. Improve dashboard hierarchy

The dashboard has strong branding, which is good. Now it needs clearer task hierarchy.

Suggested improvements:

- Give the most-used tiles like OTC, Plants, and Open Cart stronger prominence.
- Reduce competition between primary and secondary actions.
- Add short helper text or subtle cues if some sections are less obvious to first-time users.
- Improve spacing between groups so the dashboard feels more structured.

Desired result:

- Users should understand where to tap in one quick glance.

### D. Refine inventory list screens

The inventory screens should be easier to scan and feel less visually flat.

Suggested improvements:

- Make search clearer and easier to notice.
- Add stronger visual distinction between product name, stock, status, and pricing.
- Use compact chips or labels for metadata like stock level or completion state.
- Keep the newest items first, but also make the list feel ordered and tidy.
- Use better empty-state design when a category has no items.

Desired result:

- Users should be able to find, compare, and review items much faster.

### E. Improve form layout and structure

The product-entry screens contain a lot of information, so layout matters a lot.

Suggested improvements:

- Break the form into clear sections such as product info, stock, vendor, media, and pricing.
- Add visual separation between sections using cards, spacing, or headings.
- Surface important calculated values in a clear summary area.
- Use inline helper text where users may not understand what to enter.
- Keep the page from feeling like one long uninterrupted block.

Desired result:

- The form should feel guided, not heavy.

### F. Upgrade the cart and checkout design

The cart and checkout experience should feel like the most reliable part of the product.

Suggested improvements:

- Use a stronger visual summary for subtotal, discount, final amount, and item count.
- Group client details, payment details, and final confirmation more clearly.
- Add visible warning states when required information is missing.
- Make the final action area more intentional and easier to understand.
- Use stronger contrast and hierarchy in all money-related views.

Desired result:

- Users should feel confident before finalizing a deal.

### G. Improve typography and readability

Some screens rely too much on thin text and light visual emphasis.

Suggested improvements:

- Use slightly stronger font weights for key values and labels.
- Increase contrast on price, stock, summary, and detail text.
- Reserve thin weights for decorative branding moments, not operational data.
- Make sure text stays readable on compact phones.

Desired result:

- Important information should stand out instantly.

### H. Balance icons and labels better

Some screens benefit from icons, but removing too many labels can reduce clarity.

Suggested improvements:

- Keep icons where they help recognition.
- Avoid making critical actions or fields icon-only when text would improve understanding.
- Pair icons with values cleanly so the layout stays elegant and readable.
- Use a consistent icon treatment across all modules.

Desired result:

- The app should look clean without sacrificing clarity.

### I. Design better states

A polished app is not only about normal screens. It also depends on how special states look.

Suggested improvements:

- Improve empty states like no products or no saved deals.
- Design clearer incomplete, pending, and completed states.
- Add more intentional visual treatment for save success, sync issue, and action error moments.
- Use consistent banners, chips, or callouts for feedback.

Desired result:

- Every state should feel designed, not accidental.

## 3. Highest-Impact Design Priorities

If the team wants the biggest design improvement with the least confusion, focus on these first:

1. Unify the header and spacing system.
2. Improve login, cart, and checkout hierarchy.
3. Make inventory lists easier to scan.
4. Break long forms into structured sections.
5. Improve text weight, contrast, and status states.

## 4. Final Recommendation

Ashokvatika does not need a dramatic redesign. It needs a strong design polish pass.

The visual identity is already there. What will improve the app most is:

- cleaner hierarchy
- more consistent spacing
- better readability
- stronger checkout clarity
- more polished UI states

That will make the app feel more premium, more trustworthy, and easier to use every day.
